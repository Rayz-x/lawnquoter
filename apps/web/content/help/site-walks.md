## Save a walk note

1. Open Site walk in the crew app.
2. If no bid is ready, the page says "No bid packages are ready to walk."
3. Pick the bid package the note belongs to.
4. Type what you saw, or choose Dictate. If the phone has no speech recognition, the page says "This browser has no speech recognition. Type the note."
5. Drop a pin on the map. The photo has to sit on the map. If the pin is missing, the page says "Drop a pin so the photo is on the map."
6. Add a photo and save.

The note stays on that bid package with the pin, so the office can see where the photo was taken.
