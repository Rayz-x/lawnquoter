## On the agreement

Open the irrigation agreement.

1. Set Zones. The count is from 1 to 200.
2. Set Minutes per zone. Use a whole number from 1 to 180. The visit length is the zone count times these minutes.
3. Set Price per zone. Use 0 or more.
4. Choose Save irrigation plan. The page says "Irrigation plan saved".

If minutes are missing, the form says "Minutes per zone are required". If the price is missing, it says "Price per zone is required".

## Price by zone

In Services & Pricing, an irrigation service can use the rule Price per sprinkler zone. Set the amount per zone. A quote then uses the zone count on the property.

## On the visit

The crew logs each zone they check.

1. Open the visit and choose Add an irrigation zone note.
2. Type the zone number, from 1 to 64.
3. Type what you found. Keep it under 500 characters.
4. Choose Save zone note. The phone says "Zone note saved. It sends when you have signal."

A bad zone says "Zone has to be a number from 1 to 64". A blank note says "A zone note is required".
