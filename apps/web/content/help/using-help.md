## Find a topic

Type a few words in the search box on Help. Articles whose title, summary, or text include those words stay on the list. Clear the box to see every topic again.

## Open a section

Each heading on an article has its own link. The link stays the same when the page is refreshed, so you can save it or send it to someone on your team.

## Ask from a field

Some settings have a small question mark beside the label. Open it for a short note. Learn more opens the matching heading in this library. Press Escape to close the note.
