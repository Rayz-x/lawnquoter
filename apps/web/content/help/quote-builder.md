## Add a line

1. Type the line name. That is the service name the customer sees.
2. Type the price. That is what the customer pays for this line.
3. Choose Add.
4. Open More for a description, a photo link, and the choices below.

The description is the sentence under the line on the quote.

## Good, better, and best

1. Open More on a line.
2. Set Good, better, or best. No tier leaves the line as a normal service.
3. Type the same option group on each choice, such as Season plan. The customer picks one line from that group.
4. The quote shows a badge for Good, Better, or Best.

## Templates

1. Build the lines you want to reuse.
2. Type a name, such as Weekly mowing. That is the name you see when you reuse these lines later.
3. Pick a service line: Mowing, Fertilizer, Cleanup, Snow, Irrigation, Install, or Other.
4. Save the template, then apply it on a later quote to copy those lines in.

## Needs site check

A line can be marked Needs site check when you have to see the lawn before the price is firm.

1. Choose Needs site check on the line.
2. Add an optional note when the page asks.
3. The quote counts how many lines need a site check.
4. Choose Clear Needs site check when the visit is done and the price can stand.
